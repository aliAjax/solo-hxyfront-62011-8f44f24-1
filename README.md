# 马术俱乐部 · 修蹄档案（hxyfront-62011）

面向马术俱乐部蹄铁师的本地修蹄档案应用：建立马匹档案，为**左前 / 右前 / 左后 / 右后**四蹄分别记录蹄形评估、异常步态、蹄铁类型、钉位、照片备注，并按时间连续保留每匹马的全部修蹄历史。数据全部保存在本机浏览器（localStorage），刷新或重启后仍在。

## 功能

- **马匹档案**：编号（唯一校验）、马名、品种、年龄、用途、毛色、负责人、备注；支持新增、编辑、移除（移除马匹级联删除其修蹄记录）。
- **修蹄记录**：修蹄日期、下次复查日期、蹄铁师、四蹄逐项填写
  - 蹄形评估（下拉 + 自由备注）
  - 异常步态标记：9 个常用标签多选 + 跛行 0–5 级 + 人工强制标记（无标签也能标记异常）
  - 蹄铁类型、本次是否更换、钉位（1–8 号钉孔多选）、钉位备注
  - 照片上传（本地压缩后内嵌保存）+ 每张照片独立备注
- **马匹列表**：关键词搜索（编号/马名/品种/负责人）、用途筛选、状态筛选（复查逾期 / 7 天内待复查 / 最近有异常步态），空结果有空状态引导。
- **复查提醒**：按“最近一次修蹄记录”的下次复查日期，自动归类 **已逾期 / 今天到期 / 7 天内 / 已安排**，逾期优先排序。
- **四蹄对比**：任选两次修蹄记录，表格并排对比左前/右前/左后/右后的蹄形、蹄铁、钉位、异常步态、照片、备注，变化单元格标注“上次值”。
- **蹄铁更换历史**：逐蹄识别蹄铁类型变化与“本次更换”勾选，自动归档（含初次登记、裸蹄→上铁），按日期倒序展示。
- **边界处理**：
  - 所有非必填字段均可留空，页面统一以“—”占位；
  - 编号为空 / 重复、年龄越界、复查日期早于修蹄日期均有行内校验；
  - 提交使用同步锁 + 按钮禁用，双击或回车连点只产生一条记录；
  - localStorage 数据损坏时自动清洗回退，不白屏；
  - 删除采用“再点一次确认”，防止误操作；
  - 照片压缩到长边 900px 的 JPEG，超出配额时明确提示。
- 额外提供 JSON **导出备份**（页脚）。

## 本地运行

```bash
npm install
npm run dev        # http://localhost:62011
```

构建：

```bash
npm run build && npm run preview
```

## 测试

```bash
npm run typecheck     # TypeScript 严格模式类型检查
npm run test:flows    # 四条主流程 + 边界处理的逻辑测试（53 项断言，Node 内直接跑）
npm run test:e2e      # Playwright 浏览器端到端走查（44 项断言），需先 npm run dev
```

`test:e2e` 需要本机存在可用的 Chromium（`npx playwright install chromium`）。无系统 root 权限时，可从 Debian 镜像下载依赖库后用 `LD_LIBRARY_PATH` 指向解压目录运行。

端到端覆盖的四条主流程：

1. **新增**：建马 → 建修蹄记录（四蹄填写、照片、异常标记）→ 双击只产生一条 → 刷新/重开标签页数据仍在；
2. **复查提醒**：逾期 / 今天 / 7 天内三匹马的状态与排序；
3. **四蹄对比**：四蹄顺序、异常行高亮（含仅人工标记）、两次记录差异标注、异常步态筛选；
4. **蹄铁更换历史**：沿用上次草稿 → 更换蹄铁 → 历史中呈现“铝合金蹄铁 → 普通钢蹄铁”“无蹄铁（裸蹄）→ 普通钢蹄铁”。

## 数据存储

- 键名：`farrier-records-v1`（localStorage）。
- 结构：`{ version: 1, horses: Horse[], visits: Visit[] }`，每个 Visit 内含 `hooves: { LF, RF, LH, RH }` 四蹄数据；照片以 data URL 内嵌。
- 清除站点数据即清空档案；迁移时可用页脚“导出备份”。

## 技术栈

React 19 + Vite 7 + TypeScript（严格模式），无后端、无 UI 组件库，单页应用。
